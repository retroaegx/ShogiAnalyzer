# Python不要版（ネイティブ配布）

WindowsはZIPをすべて展開し、Start.batを起動します。Windows 10以降が対象です。必要なVisual C++ランタイムDLLを同梱しているため、利用者によるランタイムの別途インストールは不要です。Linuxはtar.gzを展開してターミナルで `./ShogiAnalyzer`、macOSは展開後のStart.commandから起動します。フォルダー内の `_internal` も必要です。書き込み可能な場所へ置いてください。

Python・PHPを別途入れる必要はありません。エンジン・評価関数は同梱していません。初回設定で配布元・利用規約を確認して同意すると、正規配布元から利用者のPCへ取得します。同意しない場合は取得しません。手動設定や解析なしでの利用も可能です。

OS・CPUの異なるパッケージは共用できません。Windows x64、Linux x64、Mac Intel、Mac Apple Siliconはそれぞれの環境でビルドします。Linux x64版はglibc 2.35以降（Ubuntu 22.04以降など）が対象です。

## Linuxでエンジンを自動導入する準備

Linuxではエンジンをソースからビルドするため、make・C++コンパイラーが必要です。やねうら王v8.30ではソース取得にGitも使用します。これは従来のPython版と同じ要件です。Ubuntu 22.04以降／Debian 12以降では、ターミナルで次を実行します。

```bash
sudo apt update
sudo apt install build-essential git ca-certificates
```

sudoで求められるのはLinuxのログインパスワードです。入力中は文字が表示されません。すでに必要なツールが導入されていれば、追加作業は不要です。他のLinuxではOSのパッケージ管理で同等のツールを用意してください。Python製の生成スクリプトには同梱Pythonを使うので、Pythonの別途導入は不要です。

tar.gzを展開したShogiAnalyzerフォルダーをターミナルで開き、`./ShogiAnalyzer`を実行します。初回メニューでエンジンを選び、配布元の条件を確認して同意すると、取得・展開・ビルドまで自動で進みます。ビルドには時間がかかります。現在の自動ビルドはAVX2またはSSE4.2対応のx64 CPUが対象です。手持ちの対応USIエンジンを使う場合は、初回メニューでmを選びます。

## エンジンの対応と初回設定

Windows/Linuxの自動導入設定は、やねうら王＋つようら王11mini、AobaNNUE、やねうら王v8.30＋水匠5です。Macの自動取得設定は、やねうら王v8.30＋水匠5です。Macでこの配布物を利用するために、Python・Homebrew・Xcodeを導入する必要はありません。エンジン配布物にOS・CPU対応の実行ファイルが見つからない場合は、対応USIエンジンを手動設定してください。Macの初期OS環境での導入操作は未検証です。

1. 初回起動でパスワード保護の有効/無効を選び、Enterを押します。外部公開ではy、このPCだけで使う場合はnでも利用できます。
2. 表示されたエンジン名を確認して番号を入力し、Enterを押します。番号はOSによって異なります。手動指定はm、解析なしで起動する場合はsです。
3. エンジン・評価関数の配布元と規約・ライセンスを確認し、同意する場合だけyとEnterを入力します。取得・展開・ビルドが終わるまで待ちます。
4. 同じPCのブラウザーを開き、コンソールに表示されたlocalのURL（通常はhttp://localhost:31145）をアドレス欄に入力します。パスワード保護が有効なら初回画面で設定します。他の端末から設定する場合はコンソールのセットアップコードも必要です。

## データ保存と更新

### 更新用スクリプト

先にShogiAnalyzerを終了してから、Windowsは`Update.bat`、Linuxは`./Update.sh`、Macは`Update.command`を実行します。ネイティブ配布版では、更新にも外部のPython・pip・venvは不要です。

最新リリースとOS・CPUに一致する配布物を確認し、`y`で承認すると、SHA256を照合してからアプリ部分だけを更新します。`.env`、`server/data/`（棋譜・解析結果・パスワード等）、`engines/`、`tools/cloudflared/`と、別途指定したデータ保存先は残ります。更新後は通常どおり起動してください。対応する配布物がない場合やダウンロード・検証に失敗した場合は、アプリを変更しません。

実行中のアプリと更新処理は排他制御されます。ファイルの置換や更新後の起動確認に失敗すると、旧ファイルへ戻します。電源断等で中断した場合も、同じUpdateを再実行すると残った更新用実行環境から復旧します。復旧できない場合は、表示されたバックアップの場所を残してください。一時的な更新用実行環境と旧ファイルのバックアップを置く空き容量・アプリのフォルダーへの書き込み権限が必要です。

Linux・Macでは、一時フォルダーでも実行ファイルを動かします。`/tmp`等を実行禁止（`noexec`）にしている場合は、実行できる一時フォルダーを`TMPDIR`に指定してください。

この更新機能が入っていない旧配布版からは、一度だけ以下の手動更新が必要です。ソース版のUpdateスクリプトは既存のPython環境を使用し、ネイティブ版とは別のソースZIPを取得します。

設定は実行ファイル横の `.env`、棋譜・パスワード等のデータは `server/data/` に保存します。既存環境から移す場合は停止してからこれらと `engines/`、`tools/cloudflared/` を利用者自身で移してください。別の保存先を使う場合は環境変数 `SHOGI_ANALYZER_HOME` に絶対パスを指定します。更新時はユーザーデータを残してアプリのファイルを置き換えます。

終了する場合は起動したターミナルでCtrl+Cを押してください。常駐運用は `ShogiAnalyzer --serve` を使用できます。この場合、事前に `.env` にエンジンのパス等を設定してください。

macOS版は署名・公証していません。OSの警告が出る場合は、提供元と取得元を確認したうえでOSの許可操作が必要です。Linuxはビルド環境より古いglibcでは動作しない場合があります。配布先を考慮し古い対応環境でビルドします。

開発者向け: クリーンな仮想環境へ `tools/requirements-portable.txt` を入れ、`python tools/build_portable.py` を実行します。続いて `python tools/smoke_portable.py <生成された実行ファイル>` で、PythonがPATHにない状態での通常起動とHTTP配信を検証します。生成したbuild-report.json・build-requirements.lockにはサイズ・ハッシュ・使用した依存バージョンを記録します。

Windows版をビルド・再配布する環境には、再配布権を持つVisual Studioの利用許諾とVisual Studio 2022のC++ REDISTファイルが必要です。ビルド時に署名・版・出所を検査します。これは配布者側の条件で、通常利用者にVisual Studioの導入は不要です。

同梱物の著作権・ライセンス・対応ソース・差し替え方法は、配布物のTHIRD_PARTY.txtを参照してください。開発テストには別途tests/requirements.txtを使います。

Windows版に含むMicrosoft製ランタイムにはMicrosoftの条件が適用されます。利用・再配布する場合はTHIRD_PARTY.txtの「Windowsの実行環境」と、そこに記載した付属条件を確認し、同意したうえで利用・再配布してください。これらの条件はMicrosoft製コードに対するもので、ShogiAnalyzer本体のMITライセンスを変更しません。
